# 🚀 Acelerador de Vídeos

Extensão para Google Chrome que acelera, desacelera ou reseta a velocidade de **qualquer vídeo na página**, através de **atalhos rápidos de teclado**.

---

## 🎯 Funcionalidades

- ⚡ Acelera vídeos com **Ctrl + Shift + →**
- 🐢 Desacelera vídeos com **Ctrl + Shift + ←**
- 🔁 Reseta a velocidade para **1x** com **Ctrl + Shift + ↓**
- 📺 Funciona em **qualquer site** com elemento `<video>`
- 🔔 Mostra um **indicador visual** discreto com a velocidade atual
- 🔧 Manual rápido acessível ao clicar no ícone da extensão

---

## ⌨️ **Atalhos Padrão**

| Ação | Teclas |
|------|--------|
| Acelerar vídeo | `Ctrl + Shift + →` |
| Desacelerar vídeo | `Ctrl + Shift + ←` |
| Resetar para 1x | `Ctrl + Shift + ↓` |

> ⚠️ Os atalhos funcionam apenas enquanto o vídeo está visível na aba atual.
